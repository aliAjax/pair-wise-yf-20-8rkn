# hxyfront-62008 烟花燃放脚本编排

源提示词编号：10

我想做一个面向烟花燃放编排师的燃放脚本前端工具，可以记录节目段落、烟花型号、口径、发射角度、点火时间、持续时间、安全距离和音乐时间点。页面需要有时间轴编排、燃放点位平面图、型号清单、冲突时间提示和整场节目预览。

## 技术栈

React + Vite + TypeScript

## 本地运行

```bash
npm install
npm run dev
```

开发端口：62008

## 安保放行核算

在编排点火之外，按区域人数与离场口宽度做清场放行核算：

- 通行能力：120 人/分钟/米；区域疏散秒数 = ⌈人数 ÷ 关联且开启离场口能力之和⌉
- 清场结束 = 疏散开始（首段 00:00，其后为上段实际点火）+ 最慢区域疏散秒数 + 120 秒缓冲
- 清场结束晚于编排点火即挡住，给出最早可点火时刻，可一键采用（下游段落自动顺延重算）
- 离场口关停 / 宽度调整、区域人数或点火计划变更，会使已采用的放行时刻失效并提示重算
- 时间轴展示疏散段、缓冲段、编排/实际点火与阻塞点；预警区列出阻塞原因
- 方案数据保存在浏览器 localStorage

代码按业务拆分为三个文件：

- `src/business/clearance.ts`：核算判定（纯函数）
- `src/business/storage.ts`：浏览器存储与脏数据兜底
- `src/business/ClearancePage.tsx`：编排/预警/时间轴页面
